# Event photography


## Brand rule
Do **not** place stock or AI people here in a way that could be read as DJ Merci, DJ Liz, staff, or Kingz performers.

Prefer: gear, lighting, dance floors, venues, abstract brand atmosphere, anonymous crowds from behind.

Web-optimized JPGs only. Keep masters in `/assets/raw/`.
