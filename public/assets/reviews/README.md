# Review source files (not rendered yet)

Store screenshots or exports of **real** Google / written reviews here for later wiring.

The site does **not** display testimonials until `googleReviews` is enabled and real quotes are supplied. Do not invent names, star ratings, or review text.

Suggested later fields per review: first name (or initials), event type, city, short quote, optional Google review URL.

Keep this folder out of the production UI until a reviews section is built from verified content.
