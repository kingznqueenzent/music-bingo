# LyricGrid Soundboard FX

Royalty-free-style short clips generated for LyricGrid host/stage overlays.

| File | Use |
|------|-----|
| `bingo-win.mp3` | Victory chime / cheer (Bingo Win button) |
| `wrong-buzzer.mp3` | Game-show wrong buzzer |
| `airhorn.mp3` | DJ airhorn |
| `vinyl-scratch.mp3` | Record rewind / scratch |
| `drumroll.mp3` | Tension drumroll |

Regenerate with:

```bash
npm install --no-save lamejs
node scripts/generate-sfx-mp3s.js
```
